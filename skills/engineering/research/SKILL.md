---
name: research
description: 对照高可信度的一手来源调研一个问题，并把发现作为仓库中的一个 Markdown 文件 capture 下来。适用于用户想调研某个主题、收集文档或 API 事实，或把阅读类的跑腿工作委托给一个 background agent 时。
---

启动一个 **background agent** 来做调研，这样你在它阅读的同时可以继续工作。

它的任务：

1. 对照**一手来源**调研这个问题——官方文档、源代码、spec、第一方 API——而不是对它们的二手转述。把每一条论断都追溯到拥有它的那个来源。
2. 把发现写进单个 Markdown 文件，为每条论断注明其来源。
3. 把它保存到仓库已经存放这类笔记的地方；沿用现有约定，如果没有约定，就放到一个合理的位置并说明在哪里。
