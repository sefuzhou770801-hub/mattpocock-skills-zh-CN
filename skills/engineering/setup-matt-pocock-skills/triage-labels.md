# Triage Labels

各个 skill 使用五个规范的 triage 角色。本文件把这些角色映射到本 repo 的 issue tracker 中实际使用的 label 字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue                 |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`    | 已完整定义，可交给 AFK agent             |
| `ready-for-human`          | `ready-for-human`    | 需要人类来实现                           |
| `wontfix`                  | `wontfix`            | 不会处理                                 |

当某个 skill 提到某个角色（例如 "apply the AFK-ready triage label"）时，使用本表中对应的 label 字符串。

编辑右侧一列，使其与你实际使用的词汇相匹配。
