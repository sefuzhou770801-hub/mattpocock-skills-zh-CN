# Misc

我留着但很少使用的工具——不在 plugin 中推广。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)** - 设置 Claude Code hooks，在危险的 git 命令（push、reset --hard、clean 等）执行前将其拦截。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** - 将 test 文件中的 `as` 类型断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)** - 创建包含 section、problem、solution 和 explainer 的练习目录结构。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** - 设置 Husky pre-commit hooks，集成 lint-staged、Prettier、类型检查和 test。
